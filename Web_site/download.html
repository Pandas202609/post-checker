ポストチェッカー

アプリをダウンロード

ポストチェッカーを使用するには、
以下の事前準備を行ってからアプリをダウンロードしてください。

事前準備

Windows PowerShellでの利用を想定しています。

1. Ollamaのインストール

Windows PowerShellを起動し、以下のコマンドを入力してください。 

irm https://ollama.com/install.ps1 | iex

2. PySimpleGUIのインストール

Pythonがインストールされていない場合はエラーが発生します。 Pythonをインストールした後、以下のコマンドを入力してください。 

pip install PySimpleGUI requests

3. アプリパスワードを取得

3-1. 2段階認証を設定

Googleアカウントで2段階認証を設定してください。

Googleアカウントの2段階認証の設定

上記のURLをクリックして、Googleアカウントの2段階認証を設定してください。

3-2. アプリパスワードを作成

Googleアカウントにログインした後、アプリパスワードを作成してください。

Googleアプリパスワードの作成

作成したアプリパスワードは、後で使用するため必ず控えておいてください。

4. ポストチェッカーをダウンロードして展開

以下のボタンからポストチェッカーをダウンロードしてください。

ポストチェッカーをダウンロード

ダウンロードしたZIPファイルを展開し、 C:\Users\ユーザ名\の下に配置してください。

5. ELYZA-JPのAIを使用するための設定

5-1. Llama-3-ELYZA-JP-8B-GGUFをダウンロード

以下のページから Llama-3-ELYZA-JP-8B-GGUF をダウンロードしてください。

Llama-3-ELYZA-JP-8B-GGUF

ダウンロードしたファイルを、 C:\Users\ユーザ名\ollama-models に配置してください。

5-2. Ollamaモデルの設定

Windows PowerShellを起動し、以下のコマンドを順番に入力してください。 

cd C:\Users\ユーザ名\ollama-models
ollama create elyza-jp -f Modelfile
